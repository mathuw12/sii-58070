# Sistemas Informáticos Industriales

Repositorio de prácticas de SII.

## Descripción

Juego de tenis para dos jugadores en C++ en 5 prácticas.

## Autor

Nombre y Apellido: Matias Vivanco

Matrícula: 58070

## Práctica 1: Entorno de desarrollo bajo Linux

Se crear las bases del proyecto con el Ubuntu y Github, además de añadir movimiento a los objetos a la partida.

## Práctica 2: Comunicación mediante tuberías con nombre (FIFO)

Se añade un nuevo programa logger que recibe del juego del tenis la información de cada punto marcado, además de añadir un marcado y una condición de victoria.
